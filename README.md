# nabd-tafuk-questions

## ملفات الأسئلة

يحتوي `Questions.json` على جميع المواد في قائمة واحدة، وقد أُبقي عليه للتوافق مع الاستخدامات الحالية.

كما يتوفر ملف JSON مستقل لكل مادة، ويحتوي كل ملف على كائن المادة نفسه (المعرّف والاسم والدروس والأسئلة):

| المادة | الملف |
|---|---|
| التحليل | `math.json` |
| الجبر | `math_2.json` |
| الهندسة | `math_3.json` |
| الفيزياء | `physics.json` |
| الكيمياء | `chemistry.json` |
| اللغة الإنجليزية | `english.json` |
| العلوم | `science.json` |

عند تحديث بيانات مادة، يُرجى إبقاء ملفها المنفصل و`Questions.json` متزامنين.
